\section{Preliminaries for the Online Result}\label{sec:preliminaries}

We first define the consensus-clustering objective, the vertex-arrival
model, and the measure of changes to previously assigned vertices.
We then state the auxiliary correlation-clustering guarantee used in the
online algorithm. All subsequent definitions and results in this section
concern the online part of the paper.

\paragraph{Conventions.}
For a positive integer $r$, write $[r]=\{1,\ldots,r\}$.
For a finite set $W$ and a nonnegative integer $k$, let $\binom{W}{k}$
denote the family of its $k$-element subsets; in particular,
$\binom{W}{2}$ is the set of unordered pairs of distinct elements of $W$.
For sets $X,Y$, their symmetric difference is
$X\triangle Y=(X\setminus Y)\cup(Y\setminus X)$.
The notation $\1[\mathsf{E}]$ is $1$ when the statement $\mathsf{E}$ holds
and $0$ otherwise. We use $\Prb$ and $\E$ for probability and expectation.
Unless a base is displayed, logarithms are natural.
A subscript on asymptotic $O(\cdot)$ notation lists the parameters on
which the hidden constant may depend.

\subsection{Partitions and the consensus objective}\label{subsec:partitions}

A \emph{partition} $C$ of a finite set $W$ is a collection of nonempty,
pairwise disjoint subsets whose union is $W$. Its parts are called
\emph{clusters}. The empty set has the unique empty partition.
For $u,v\in W$, write $u\sim_C v$ if they belong to the same cluster.
The set of pairs joined by $C$ is
\[
  E_W^+(C)=\bigl\{\{u,v\}\in\tbinom{W}{2}:u\sim_C v\bigr\}.
\]
We omit the subscript $W$ when the ground set is clear.

The distance between two partitions counts the pairs on which their
decisions to join or separate disagree.

\begin{definition}[Partition distance]\label{def:partition-distance}
For partitions $C,D$ of the same set $W$, define
\begin{equation}\label{eq:partition-distance}
  d_W(C,D)=|E_W^+(C)\triangle E_W^+(D)|.
\end{equation}
We write $d(C,D)$ when both partitions have an unambiguous ground set.
\end{definition}

For $U\subseteq W$, the \emph{restriction} $C|_U$ is the partition obtained
by intersecting every cluster of $C$ with $U$ and removing empty
intersections. The following elementary properties will be used throughout:
partition distance satisfies the triangle inequality, and restriction can
only decrease it.

\begin{observation}\label{obs:partition-metric}
For partitions $C,D,F$ of $W$ and a subset $U\subseteq W$,
\begin{align}
  d_W(C,D)&\le d_W(C,F)+d_W(F,D), \label{eq:partition-triangle}\\
  d_U(C|_U,D|_U)&\le d_W(C,D). \label{eq:restriction-distance}
\end{align}
\end{observation}
\begin{proof}
Associate a partition with its binary incidence vector on $\binom{W}{2}$:
a coordinate is $1$ precisely when its pair is joined. Partition distance
is the number of coordinates on which two such vectors differ. This gives
the triangle inequality coordinate by coordinate. Restriction deletes
coordinates outside $\binom{U}{2}$ and therefore cannot increase the
number of disagreements.
\end{proof}

Let $m$ be a positive integer, and let
$\Pp=(P_1,\ldots,P_m)$ be an indexed collection of input partitions of $W$.
Repeated partitions are allowed and retain their separate indices.
The \emph{consensus cost} of a partition $C$ and the optimum cost are
\begin{equation}\label{eq:consensus-objective}
  \cost_{\Pp}(C)=\frac1m\sum_{i=1}^m d_W(C,P_i),
  \qquad
  \OPT(\Pp)=\min_{\text{partitions }C\text{ of }W}\cost_{\Pp}(C).
\end{equation}
We use the average, rather than the sum, of the input distances. This
normalization does not affect approximation ratios.
Applying \eqref{eq:partition-triangle} to each input gives the useful
comparison inequality
\begin{equation}\label{eq:cost-comparison}
  \cost_{\Pp}(C)\le \cost_{\Pp}(F)+d_W(C,F)
\end{equation}
for any two partitions $C,F$ of $W$.

\subsection{The online model and recourse}\label{subsec:online-model}

Fix a vertex set $V=\{v_1,\ldots,v_n\}$ of size $n\ge1$ and $m$
input partitions $P_1,\ldots,P_m$ of $V$.
The vertices arrive in the order $v_1,\ldots,v_n$.
We assume that $n$ and $m$ are known to the algorithm.
At time $t\in[n]$, the active vertex set and the restricted input collection
are
\[
  V_t=\{v_1,\ldots,v_t\},\qquad
  P_i^t=P_i|_{V_t}\quad(i\in[m]),\qquad
  \Pp^t=(P_1^t,\ldots,P_m^t).
\]
For convenience, $V_0=\varnothing$.
When $v_t$ arrives, the algorithm receives its cluster label in each
input partition. More precisely, input $i$ provides a persistent label
$c^i(v)$ for each vertex $v$, with
$c^i(u)=c^i(v)$ if and only if $u\sim_{P_i}v$.
Previously revealed labels do not change.
Thus arrival reveals how the new vertex relates to every earlier vertex
in every input, while all relations between earlier vertices remain fixed.

Write
\begin{equation}\label{eq:prefix-objective}
  \cost_t(C)=\cost_{\Pp^t}(C),
  \qquad
  \OPT_t=\OPT(\Pp^t).
\end{equation}
For the analysis, fix an optimal partition $F_t^*$ of $V_t$ for each $t$,
using a deterministic tie-breaking rule independent of the algorithm's
random choices. These reference partitions are not available to the
algorithm. Restricting an optimal partition at time $t+1$ to $V_t$
and using \eqref{eq:restriction-distance} shows that
$\OPT_t\le\OPT_{t+1}$.

After processing $v_t$, an online algorithm outputs a partition $C_t$ of
$V_t$. For a number $R\ge1$, it is \emph{$R$-competitive} on an execution
if $\cost_t(C_t)\le R\OPT_t$ at every time $t$.
An \emph{oblivious instance} is one in which the full input partitions
and the arrival order are fixed independently of the algorithm's random
choices. All probability guarantees below concern this model.

We measure changes to the output through persistent cluster identifiers.
Specifically, the algorithm assigns each active vertex $v$ an identifier
$\lambda_t(v)$, and two active vertices belong to the same output cluster
if and only if their identifiers agree.
For a vertex $v_s$ arriving at time $s$, its \emph{recourse} is
\begin{equation}\label{eq:recourse-definition}
  \operatorname{rec}(v_s)
  =\sum_{t=s+1}^n
    \1[\lambda_t(v_s)\ne\lambda_{t-1}(v_s)].
\end{equation}
The initial assignment is free. Every subsequent identifier change
counts, including a change that only renames a cluster.
A per-vertex recourse bound controls \eqref{eq:recourse-definition}
separately for every vertex, rather than only its sum over all vertices.

\subsection{An auxiliary online correlation-clustering algorithm}
\label{subsec:agreement}

A \emph{complete signed graph} $H$ on $W$ assigns either a positive or
a negative sign to every pair in $\binom{W}{2}$.
Let $E^+(H)$ denote its set of positive pairs; all other pairs are negative.
The correlation-clustering error of a partition $C$ of $W$ is
\begin{equation}\label{eq:cc-objective}
  \err_H(C)=|E^+(H)\triangle E_W^+(C)|,
  \qquad
  \OPT_{\rm CC}(H)
  =\min_{\text{partitions }C\text{ of }W}\err_H(C).
\end{equation}
Thus an error is either a positive pair separated by $C$ or a negative pair
joined by $C$. The positive relation of $H$ need not itself be a partition.
Nevertheless, the same coordinatewise argument as in
\cref{obs:partition-metric} gives
\begin{equation}\label{eq:signed-comparison}
  d_W(C,F)\le \err_H(C)+\err_H(F)
\end{equation}
for any partitions $C,F$ of $W$.

For $U\subseteq W$, write $H|_U$ for the signed graph induced on $U$.
A vertex-arrival signed-graph sequence consists of graphs $H_t$ on $V_t$
such that $H_{t+1}|_{V_t}=H_t$: signs between old vertices never change.
We use the deterministic Online Agreement algorithm of
Cohen-Addad et al.~\cite{cohen2022online}, denoted by $\Agree$, on such
sequences. A \emph{persistent execution} means that one copy of this
algorithm processes the whole sequence without being restarted.
Its output at time $t$ is denoted by $D_t$.

Informally, $\Agree$ maintains a constant-factor approximation at every
prefix while changing each vertex's cluster identifier only logarithmically
many times. Let $\eta\ge1$ denote its approximation constant and
$q_{\rm A}>0$ the constant in its per-vertex recourse bound.
We use the following interface.

\begin{theorem}[Online Agreement {\cite[Theorems E.2 and F.1]{cohen2022online}}]
\label{thm:agree-blackbox}
There are absolute constants $\eta\ge1$ and $q_{\rm A}>0$ and a
deterministic algorithm $\Agree$ such that, on every vertex-arrival
sequence of complete signed graphs, a persistent execution satisfies
\[
  \err_{H_t}(D_t)\le\eta\,\OPT_{\rm CC}(H_t)
  \qquad\text{for every }t\in[n].
\]
Its output admits persistent cluster identifiers for which every vertex
has at most $q_{\rm A}\lceil\log_2 n\rceil$ changes.
\end{theorem}

Fix an implementation and its internal parameters and tie-breaking rules
once and for all. We retain the symbolic constant $\eta$ in our competitive
ratio, rather than assigning it a numerical value not specified by the
interface. The auxiliary objective \eqref{eq:cc-objective} is unweighted.
It will be used only to interpret the majority of three inputs; the
algorithm's final output is evaluated by the full consensus objective
\eqref{eq:prefix-objective}.

\section{Online Consensus Clustering}\label{sec:online}

Our main online result gives a competitive ratio strictly below $2$ with
polylogarithmic recourse for every vertex.
The approximation guarantee holds simultaneously at all prefixes with
an explicitly controlled probability of failure, whereas the recourse
guarantee holds for every outcome of the random choices.
The achievable gap below $2$ depends only on the approximation constant
$\eta$ of $\Agree$ from \cref{thm:agree-blackbox}.
Let $\eps$ be an accuracy parameter satisfying
$0<\eps<2/(3\eta+5)$, and let $\zeta\in(0,1)$ be the permitted probability
of any approximation failure over the entire execution.

\begin{theorem}[Online consensus clustering]\label{thm:online-main}
There is a randomized online algorithm that, for every known horizon
$n$ and every oblivious vertex-arrival instance with $m$ input partitions,
has the following guarantees. With probability at least $1-\zeta$,
its outputs satisfy
\begin{equation}\label{eq:online-ratio}
  \cost_t(C_t)
  \le
  \left(2-\frac{2}{3\eta+5}+\eps\right)\OPT_t
  \qquad\text{simultaneously for all }t\in[n].
\end{equation}
For every realization of its random choices and every vertex $v$,
\begin{equation}\label{eq:online-recourse-main}
  \operatorname{rec}(v)
  =
  O_{\eta,q_{\rm A}}\!\left(
    \eps^{-2}
    \log\frac{2n}{\zeta}\,
    \log\frac{2mn}{\zeta}
  \right).
\end{equation}
\end{theorem}

For fixed $\eta,q_{\rm A},\eps$, the bound in
\eqref{eq:online-recourse-main} is polylogarithmic in the instance size
and the inverse failure probability. We compute candidate costs exactly
with respect to all $m$ inputs. The theorem concerns approximation and
recourse; it does not assert a near-linear running time.

\paragraph{Degenerate cases.}
If $n=1$, the unique partition is optimal and incurs no recourse.
If $m=1$, following the single input is optimal.
If $m=2$, following $P_1^t$ is optimal at every time, since for every
partition $F$ of $V_t$,
\[
  \cost_t(F)
  =\frac{d(F,P_1^t)+d(F,P_2^t)}2
  \ge\frac{d(P_1^t,P_2^t)}2
  =\cost_t(P_1^t).
\]
Following an input uses its persistent labels and incurs no recourse.
We therefore assume $n\ge2$ and $m\ge3$ for the rest of the section.

\paragraph{Proof overview.}
The algorithm maintains a small family of candidate processes, each
proposing a partition at every prefix.
Some candidates simply follow sampled input partitions.
Others run persistent copies of $\Agree$ on signed graphs built from
sampled triples of input indices: a pair is positive precisely when at
least two of the three inputs join it.
For any fixed terminal prefix, either many inputs already have cost below
twice the optimum, or the triangle inequalities through an optimal
partition are nearly tight for a random triple of inputs.
We show that such a triple produces a candidate
whose cost is small throughout its entire history, relative to the optimum
at that terminal prefix.

This history guarantee is what permits low-recourse selection.
We score each candidate by its largest cost so far and keep the selected
candidate until it crosses a fixed multiplicative threshold.
Candidates discarded at a threshold never become eligible again at that
threshold, since their history scores cannot decrease.
There are few thresholds and few candidates, so there are few changes
of the selected candidate.
The next subsections establish the structural bounds, construct the
candidate family, and analyze this selection rule before completing
the proof of \cref{thm:online-main}.

\subsection{Majority graphs and triangle-inequality slack}
\label{subsec:majority-slack}

Fix a time $t\in[n]$ and a reference partition $F$ of $V_t$.
For an input index $i\in[m]$, let
\[
  I_i^t(F)=E^+(F)\triangle E^+(P_i^t)
\]
be its set of errors relative to $F$.
For distinct indices $i,j$, define their \emph{triangle-inequality slack}
around $F$ by
\begin{equation}\label{eq:pair-slack}
  \Delta_{ij}^t(F)
  =d(F,P_i^t)+d(F,P_j^t)-d(P_i^t,P_j^t).
\end{equation}
This number is nonnegative by \eqref{eq:partition-triangle}.

For a triple $Q\in\binom{[m]}{3}$, its \emph{total slack} is
\[
  \Delta_Q^t(F)=\sum_{\{i,j\}\in\binom{Q}{2}}\Delta_{ij}^t(F).
\]
The indices in a triple are distinct, although their input partitions
may coincide.
The \emph{majority graph} $H_Q(t)$ is the complete signed graph on $V_t$
in which a pair is positive if at least two of the three indexed inputs
join it, and negative otherwise.
Finally, let
\[
  B_Q^t(F)=E^+(H_Q(t))\triangle E^+(F)
\]
be the pairs on which this majority relation disagrees with $F$.

The next lemma identifies pairwise slack exactly with overlapping input
errors. Since a majority error requires two input errors, the number of
majority errors is at most half the total slack.

\begin{lemma}[Majority errors and half-slack]\label{lem:majority-half-slack}
For every time $t$, reference partition $F$ of $V_t$, and distinct
indices $i,j\in[m]$,
\begin{equation}\label{eq:overlap-identity}
  \Delta_{ij}^t(F)=2|I_i^t(F)\cap I_j^t(F)|.
\end{equation}
Consequently, for every $Q\in\binom{[m]}{3}$,
\begin{equation}\label{eq:half-slack}
  |B_Q^t(F)|=\err_{H_Q(t)}(F)\le\frac12\Delta_Q^t(F).
\end{equation}
\end{lemma}
\begin{proof}
The symmetric difference of $I_i^t(F)$ and $I_j^t(F)$ is
$E^+(P_i^t)\triangle E^+(P_j^t)$. Hence
\[
  d(P_i^t,P_j^t)
  =|I_i^t(F)|+|I_j^t(F)|
     -2|I_i^t(F)\cap I_j^t(F)|.
\]
Subtracting this identity from
$d(F,P_i^t)+d(F,P_j^t)=|I_i^t(F)|+|I_j^t(F)|$
proves \eqref{eq:overlap-identity}.

A pair belongs to $B_Q^t(F)$ if and only if at least two inputs indexed
by $Q$ disagree with $F$ on that pair. Therefore
\[
  B_Q^t(F)
  =
  \bigcup_{\{i,j\}\in\binom{Q}{2}}
       \bigl(I_i^t(F)\cap I_j^t(F)\bigr).
\]
Bounding the size of this union by the sum of its set sizes and applying
\eqref{eq:overlap-identity} gives \eqref{eq:half-slack}.
\end{proof}

\subsection{Few good inputs imply many useful triples}
\label{subsec:triple-averaging}

We next relate the costs of the input partitions to the slack of a random
triple. This is the metric averaging principle underlying the sampling
framework of Carmel et al.~\cite{carmel2026scalable}; we give the complete
argument specialized to triples.

Fix $t\in[n]$, and let $\alpha\in(0,1)$ measure a desired improvement
over ratio $2$. Define the set of \emph{good input indices} by
\begin{equation}\label{eq:good-inputs}
  J_t(\alpha)
  =\bigl\{i\in[m]:
      \cost_t(P_i^t)\le(2-\alpha)\OPT_t\bigr\}.
\end{equation}
Let $\rho\in[0,1-\alpha]$ be an upper bound on the fraction of such
indices, and let $Q$ be uniformly distributed over $\binom{[m]}{3}$.
Informally, if few inputs are good, then the average distance between
inputs is large; this leaves little average triangle-inequality slack
around the optimum.

\begin{lemma}[Triple-slack averaging]\label{lem:universal-averaging}
If $|J_t(\alpha)|\le\rho m$, then
\begin{equation}\label{eq:expected-slack}
  \E_Q[\Delta_Q^t(F_t^*)]
  \le 3(\alpha+2\rho)\OPT_t.
\end{equation}
\end{lemma}
\begin{proof}
Define the aggregate input cost and total pairwise slack by
\[
  T_t=\sum_{i=1}^m\cost_t(P_i^t),
  \qquad
  S_t=\sum_{1\le i<j\le m}\Delta_{ij}^t(F_t^*).
\]
At least $(1-\rho)m$ input indices have cost greater than
$(2-\alpha)\OPT_t$. Discarding the costs of all remaining inputs gives
\begin{equation}\label{eq:aggregate-input-lower}
  T_t\ge (1-\rho)m(2-\alpha)\OPT_t.
\end{equation}
Each pairwise input distance occurs twice in the definition of $T_t$,
so
\[
  T_t=\frac2m\sum_{1\le i<j\le m}d(P_i^t,P_j^t).
\]
Also, every distance $d(F_t^*,P_i^t)$ occurs $m-1$ times in the sum
defining $S_t$. Since $\sum_i d(F_t^*,P_i^t)=m\OPT_t$,
\begin{align}
  S_t
  &=m(m-1)\OPT_t-\frac m2T_t \notag\\
  &\le\frac m2\bigl[m(\alpha+2\rho-\alpha\rho)-2\bigr]\OPT_t
      \notag\\
  &\le\frac m2\bigl[m(\alpha+2\rho)-2\bigr]\OPT_t.
       \label{eq:total-slack-upper}
\end{align}
A fixed unordered pair of input indices appears in a uniform triple
with probability $6/(m(m-1))$. Thus
\[
  \E_Q[\Delta_Q^t(F_t^*)]
  =\frac{6S_t}{m(m-1)}
  \le
  3\frac{m(\alpha+2\rho)-2}{m-1}\OPT_t.
\]
Finally, $\rho\le1-\alpha$ implies $\alpha+2\rho\le2$, and hence
\[
  \frac{m(\alpha+2\rho)-2}{m-1}
  \le\alpha+2\rho.
\]
This proves the claimed expectation bound.
\end{proof}

The expectation bound yields a quantitative sampling guarantee.
For the following corollary, additionally assume $\rho>0$.
Increasing the slack threshold by $3\rho\OPT_t$ ensures a probability
of success proportional to $\rho$.

\begin{corollary}[A useful random triple]\label{cor:low-slack-triple}
Under the assumptions of \cref{lem:universal-averaging},
\begin{equation}\label{eq:useful-triple-prob}
  \Prb_Q\!\left[
    \Delta_Q^t(F_t^*)\le3(\alpha+3\rho)\OPT_t
  \right]
  \ge\frac{\rho}{\alpha+3\rho}.
\end{equation}
\end{corollary}
\begin{proof}
If $\OPT_t=0$, every input partition equals $F_t^*$, because all
summands in its consensus cost are nonnegative and sum to zero.
All slacks then vanish, and the displayed probability is $1$.
Suppose instead that $\OPT_t>0$. Markov's inequality and
\eqref{eq:expected-slack} give
\[
  \Prb_Q\!\left[
    \Delta_Q^t(F_t^*)>3(\alpha+3\rho)\OPT_t
  \right]
  \le\frac{\alpha+2\rho}{\alpha+3\rho}.
\]
Taking complements proves the claim.
\end{proof}

\subsection{The sampled candidate processes}\label{subsec:online-candidates}

A \emph{candidate process} is a partition trajectory, together with
persistent cluster identifiers, maintained at every arrival.
We construct a fixed, randomly sampled family of these processes.
Every process continues to receive all arrivals, including those times
when it is not selected for the output.

The balancing constant, sampling parameter, and target bound for the
candidate histories are, respectively,
\begin{equation}\label{eq:online-parameters}
  \alpha_*=\frac{2}{3\eta+5},
  \qquad
  \rho=\frac{\eps}{9(\eta+1)},
  \qquad
  R=2-\alpha_*+\frac{\eps}{2}.
\end{equation}
Here $\rho$ is the value used in the preceding sampling bounds.
Since $\eta\ge1$ and $0<\eps<\alpha_*\le1/4$, we have
$0<\rho<1-\alpha_*$ and $R<2$.

Let the numbers of input and triple candidates be
\begin{equation}\label{eq:candidate-sample-sizes}
  L_{\rm in}
  =\left\lceil\frac1\rho\log\frac{2n}{\zeta}\right\rceil,
  \qquad
  L_{\rm tri}
  =\left\lceil
      \frac{\alpha_*+3\rho}{\rho}\log\frac{2n}{\zeta}
    \right\rceil.
\end{equation}
Set $K=L_{\rm in}+L_{\rm tri}$ and define the index sets
\[
  \A=[K],\qquad
  \A_{\rm in}=[L_{\rm in}],\qquad
  \A_{\rm tri}=\{L_{\rm in}+1,\ldots,K\}.
\]
For each $a\in\A_{\rm in}$, sample an input index $i_a$ uniformly from
$[m]$. For each $a\in\A_{\rm tri}$, sample a triple $Q_a$ uniformly
from $\binom{[m]}{3}$. All these draws are mutually independent.
Sampling is with replacement across candidate indices.
In particular, two occurrences of the same input or triple remain
separately indexed candidates. The resulting family size satisfies
\begin{equation}\label{eq:candidate-count}
  K=O_\eta\!\left(\eps^{-1}\log\frac{2n}{\zeta}\right).
\end{equation}

For each $a\in\A$, let $A_a(t)$ denote its partition at time $t$.
The processes are defined as follows.
\begin{enumerate}
  \item For $a\in\A_{\rm in}$, set $A_a(t)=P_{i_a}^t$ and use the
  persistent input labels as cluster identifiers.
  \item For $a\in\A_{\rm tri}$, run one persistent copy of $\Agree$ on
  $H_{Q_a}(1),\ldots,H_{Q_a}(n)$ and let $A_a(t)$ be its output.
\end{enumerate}
The latter is a valid vertex-arrival signed-graph sequence:
the three input restrictions never change their decisions on pairs of
already arrived vertices. The sampled indices are the only random
choices of the algorithm; the copies of $\Agree$ are deterministic.

Write $\lambda_t^a(v)$ for the local identifier of $v$ in candidate $a$.
For a vertex $v_s$, define its \emph{internal recourse} in that candidate by
\[
  \operatorname{rec}_a(v_s)
  =\sum_{t=s+1}^n
     \1[\lambda_t^a(v_s)\ne\lambda_{t-1}^a(v_s)].
\]
Input candidates have zero internal recourse, and
\cref{thm:agree-blackbox} gives
\begin{equation}\label{eq:internal-recourse}
  \operatorname{rec}_a(v)\le q_{\rm A}\lceil\log_2 n\rceil
  \qquad(a\in\A_{\rm tri}).
\end{equation}

The selector will use the following exact scores:
\begin{equation}\label{eq:history-scores}
  f_a(t)=\cost_t(A_a(t)),\qquad
  G_a(t)=\max_{1\le u\le t}f_a(u),\qquad
  M_t=\min_{a\in\A}G_a(t).
\end{equation}
Thus $f_a(t)$ is a current cost, $G_a(t)$ is a \emph{history score},
and $M_t$ is the smallest history score currently available.
Set $G_a(0)=0$. We update a history score by
$G_a(t)=\max\{G_a(t-1),f_a(t)\}$.
All costs are evaluated against the complete collection $\Pp^t$,
not only the inputs used to generate a candidate.

History scores do not decrease, even when an auxiliary clustering
changes. For an input candidate, the current cost itself already has
this monotonicity.

\begin{observation}\label{obs:history-monotonicity}
For every $a\in\A$, $G_a(t)$ is nondecreasing in $t$, and so is $M_t$.
For every $a\in\A_{\rm in}$, $G_a(t)=f_a(t)$ at every time.
\end{observation}
\begin{proof}
The first assertion follows from taking a maximum over a growing set
of times. A minimum of coordinatewise nondecreasing quantities is also
nondecreasing, proving the assertion for $M_t$.
For an input candidate, every pairwise distance
$d(P_{i_a}^t,P_j^t)$ is nondecreasing as vertices arrive: old pair
decisions are fixed, and newly available pairs contribute nonnegative
additional errors. Their average $f_a(t)$ is therefore nondecreasing
and equals its own historical maximum.
\end{proof}

\subsection{A triple controls its entire history}\label{subsec:online-history}

The main reason to use a persistent $\Agree$ execution is stronger than
its approximation guarantee at the current prefix.
If a sampled triple has small slack at time $t$, then its candidate
has been inexpensive at every earlier time, measured against $\OPT_t$.
We compare all earlier outputs to restrictions of the same terminal
optimum $F_t^*$.

To make this comparison precise, fix $t\in[n]$ and
$a\in\A_{\rm tri}$, and write $Q=Q_a$.
For each $u\in[t]$, define the restricted majority-error set
\[
  B_{Q,t,u}=B_Q^t(F_t^*)\cap\binom{V_u}{2}.
\]
Consistency of the input restrictions gives
\begin{equation}\label{eq:restricted-majority-errors}
  \err_{H_Q(u)}(F_t^*|_{V_u})=|B_{Q,t,u}|,
  \qquad
  B_{Q,t,u}\subseteq B_Q^t(F_t^*).
\end{equation}
The reference partition in this expression is the restriction of
$F_t^*$, not an independently chosen optimum at time $u$.

\begin{lemma}[History bound for a triple candidate]
\label{lem:triple-history-bound}
For every sampled triple candidate $a\in\A_{\rm tri}$ and every $t\in[n]$,
\begin{equation}\label{eq:triple-history-bound}
  G_a(t)
  \le \OPT_t+\frac{\eta+1}{2}\Delta_{Q_a}^t(F_t^*).
\end{equation}
This bound holds for every realization of the sampled family.
\end{lemma}
\begin{proof}
Fix $u\in[t]$. Since $F_t^*|_{V_u}$ is a valid partition of $V_u$,
\cref{thm:agree-blackbox} and \eqref{eq:restricted-majority-errors} imply
\[
  \err_{H_Q(u)}(A_a(u))
  \le \eta\,\OPT_{\rm CC}(H_Q(u))
  \le \eta\,\err_{H_Q(u)}(F_t^*|_{V_u})
  =\eta|B_{Q,t,u}|.
\]
Applying \eqref{eq:signed-comparison} therefore gives
\begin{equation}\label{eq:history-distance-bound}
  d(A_a(u),F_t^*|_{V_u})
  \le(\eta+1)|B_{Q,t,u}|.
\end{equation}
On the other hand, restricting each pairwise input distance yields
\[
  \cost_u(F_t^*|_{V_u})
  =\frac1m\sum_{i=1}^m
       d(F_t^*|_{V_u},P_i^u)
  \le\frac1m\sum_{i=1}^m d(F_t^*,P_i^t)
  =\OPT_t.
\]
Combining this inequality with \eqref{eq:cost-comparison},
\eqref{eq:history-distance-bound}, and \cref{lem:majority-half-slack},
we obtain
\begin{align*}
  f_a(u)
  &\le\cost_u(F_t^*|_{V_u})+d(A_a(u),F_t^*|_{V_u})\\
  &\le\OPT_t+(\eta+1)|B_{Q,t,u}|\\
  &\le\OPT_t+(\eta+1)|B_Q^t(F_t^*)|\\
  &\le\OPT_t+\frac{\eta+1}{2}\Delta_Q^t(F_t^*).
\end{align*}
The right-hand side does not depend on $u$. Taking the maximum over
$u\in[t]$ proves the lemma.
\end{proof}

No optimality assertion about $F_t^*|_{V_u}$ is needed.
Only its feasibility at time $u$ and the monotonicity of pairwise
disagreement under restriction are used.
This is also why a guarantee merely in expectation at each prefix
would not directly provide the deterministic history bound above.

\subsection{A good history at every prefix}\label{subsec:online-sampling}

We now combine the two candidate types.
At a fixed time $t$, write $J_t=J_t(\alpha_*)$, using
\eqref{eq:good-inputs}. If $|J_t|\ge\rho m$, input sampling finds a good
input with high probability. Otherwise triple sampling finds a
small-slack triple, whose history is controlled by
\cref{lem:triple-history-bound}.
The constants in \eqref{eq:online-parameters} balance these two alternatives.

\begin{lemma}[A good candidate at a fixed prefix]\label{lem:fixed-prefix}
For every fixed $t\in[n]$,
\[
  \Prb[M_t\le R\OPT_t]\ge1-\frac{\zeta}{n}.
\]
\end{lemma}
\begin{proof}
First suppose $|J_t|\ge\rho m$.
A uniform input index belongs to $J_t$ with probability at least $\rho$.
The probability that all $L_{\rm in}$ input draws miss $J_t$ is at most
\[
  (1-\rho)^{L_{\rm in}}
  \le e^{-\rho L_{\rm in}}
  \le\frac{\zeta}{2n}.
\]
Whenever a sampled index $i_a$ is in $J_t$,
\cref{obs:history-monotonicity} gives
\[
  G_a(t)=\cost_t(P_{i_a}^t)
  \le(2-\alpha_*)\OPT_t
  \le R\OPT_t.
\]

Now suppose $|J_t|<\rho m$.
By \cref{cor:low-slack-triple}, a uniform triple satisfies
\[
  \Delta_Q^t(F_t^*)\le3(\alpha_*+3\rho)\OPT_t
\]
with probability at least $\rho/(\alpha_*+3\rho)$.
The probability that no sampled triple satisfies this inequality is at most
\[
  \left(1-\frac{\rho}{\alpha_*+3\rho}\right)^{L_{\rm tri}}
  \le
  \exp\!\left(-\frac{\rho L_{\rm tri}}{\alpha_*+3\rho}\right)
  \le\frac{\zeta}{2n}.
\]
For a successful triple occurrence $a$, \cref{lem:triple-history-bound}
implies
\begin{align*}
  G_a(t)
  &\le
  \left(1+\frac{3(\eta+1)}2(\alpha_*+3\rho)\right)\OPT_t\\
  &=
  \left(2-\alpha_*+\frac{9(\eta+1)}2\rho\right)\OPT_t\\
  &=R\OPT_t.
\end{align*}
The second line uses
$1+\frac{3(\eta+1)}2\alpha_*=2-\alpha_*$, which follows directly from
$\alpha_*=2/(3\eta+5)$.
The last line uses the definition of $\rho$.
In either alternative the failure probability is at most
$\zeta/(2n)$, and therefore at most $\zeta/n$.
\end{proof}

Define the event that a good history exists at every prefix by
\begin{equation}\label{eq:simultaneous-event}
  \mathcal E=\{M_t\le R\OPT_t\text{ for all }t\in[n]\}.
\end{equation}
The same sampled family is used for all prefixes.
A union bound suffices to obtain the simultaneous guarantee; independence
between different times is unnecessary.

\begin{lemma}[Simultaneous history guarantee]\label{lem:simultaneous-history-event}
The event $\mathcal E$ has probability at least $1-\zeta$.
Equivalently, with this probability, for every $t\in[n]$ there is a
candidate index $b_t\in\A$ such that
\[
  \max_{1\le u\le t}\cost_u(A_{b_t}(u))\le R\OPT_t.
\]
\end{lemma}
\begin{proof}
For each fixed $t$, \cref{lem:fixed-prefix} bounds the probability of
$M_t>R\OPT_t$ by $\zeta/n$. Summing these probabilities over $n$
prefixes proves the claim.
The equivalent formulation follows from the definitions of $G_a(t)$
and $M_t$ in \eqref{eq:history-scores}.
\end{proof}

The witness $b_t$ may depend on the terminal time $t$.
The lemma does not require one candidate to serve all terminal times.
The known horizon determines the sample sizes, and the oblivious-instance
assumption ensures that each fixed prefix and its chosen optimum are
independent of the initial samples.

\subsection{Selecting a candidate with few changes}\label{subsec:online-selection}

It remains to turn the existence of a good candidate history into one
online output trajectory. The selection rule below is deterministic
once the candidate processes are fixed. Its validity and recourse bound
do not depend on the event $\mathcal E$.

Set $\theta=\eps/4$.
Let $a_t\in\A$ denote the selected candidate at time $t$.
The output partition and its identifiers are
\begin{equation}\label{eq:output-identifiers}
  C_t=A_{a_t}(t),
  \qquad
  \lambda_t(v)=(a_t,\lambda_t^{a_t}(v))
  \quad(v\in V_t).
\end{equation}
Including the candidate index makes identifiers from distinct processes
different, even if their local names happen to coincide.
An \emph{outer switch} is a time $t\ge2$ with $a_t\ne a_{t-1}$.

The \emph{zero stage} consists of prefixes with $M_t=0$.
During this stage, retain the selected candidate while its history
score remains zero, and replace it with any zero-score candidate
otherwise.

After $M_t$ becomes positive, group consecutive prefixes into
\emph{positive phases}. A phase begins at a time $t_0$ with
\emph{baseline} $B=M_{t_0}>0$, and its baseline stays fixed.
Its \emph{threshold} is $(1+\theta)B$.
A candidate is \emph{eligible} in this phase at time $t$ if
$G_a(t)<(1+\theta)B$.
At the start of a phase, choose a candidate minimizing $G_a(t_0)$.
Within a phase, keep the selected candidate until it is no longer
eligible, then replace it with an eligible candidate.
A candidate removed in this way is \emph{discarded} for that phase;
let $D\subseteq\A$ denote the set of discarded candidates.
When $M_t$ reaches the threshold, start a new phase before choosing
the output. In particular, phase changes take precedence over
discarding individual candidates.
Fix any deterministic tie-breaking rule for all selections.

% Bottom placement keeps the pseudocode after the definitions it uses.
\begin{paperalgorithm}[!b]
\centering
\fbox{\begin{minipage}{0.94\linewidth}
\textbf{Initialization.}
Sample the candidate family as in \cref{subsec:online-candidates}.
Initialize every process, set $G_a(0)=0$ for each $a\in\A$, and leave
the selected index and phase undefined.

\medskip
\textbf{On arrival of $v_t$.}
\begin{enumerate}
  \item Advance every candidate process to time $t$.
  Compute $f_a(t)$, update $G_a(t)$, and compute $M_t$.
  \item If $M_t=0$, retain the previous index if one exists and has
  history score zero; otherwise choose any index with history score zero.
  Output the partition and identifiers from
  \eqref{eq:output-identifiers}, and finish this arrival.
  \item If no positive phase has started, begin one with
  $B=M_t$ and $D=\varnothing$, and choose an index minimizing $G_a(t)$.
  \item Otherwise, if $M_t\ge(1+\theta)B$, begin a new phase with
  $B=M_t$ and $D=\varnothing$, and choose an index minimizing $G_a(t)$.
  \item Otherwise, retain the previous index if it is eligible.
  If it is not, add it to $D$ and choose any eligible index outside $D$.
  \item Output the partition and identifiers from
  \eqref{eq:output-identifiers}.
\end{enumerate}
Steps 3--5 are mutually exclusive branches.
Every copy of $\Agree$ persists throughout all phases.
\end{minipage}}
\caption{Selection by monotone history scores.}
\label{alg:online-selection}
\end{paperalgorithm}

The rule is stated explicitly in \cref{alg:online-selection}.
At a zero-score prefix it outputs cost zero.
At a positive prefix, its cost is at most a factor $1+\theta$ above
the smallest available history score.

\begin{lemma}[Deterministic selection guarantee]\label{lem:online-phase-cost}
The selection rule always has a valid candidate to choose, and its
output satisfies
\begin{equation}\label{eq:selection-cost}
  \cost_t(C_t)\le(1+\theta)M_t
  \qquad\text{for every }t\in[n].
\end{equation}
This statement holds for every realization of the sampled family.
\end{lemma}
\begin{proof}
If $M_t=0$, a zero-score candidate exists by the definition of a minimum.
Its current cost is at most its history score and hence is zero.

Suppose $M_t>0$.
At a phase start, a minimizing candidate has score $M_t=B<(1+\theta)B$,
so it is eligible. At any subsequent time at which the phase continues,
$M_t<(1+\theta)B$, so some minimizing candidate is still eligible.
A discarded candidate had score at least $(1+\theta)B$ when removed.
By \cref{obs:history-monotonicity}, it never becomes eligible again
during this phase. Thus whenever a replacement is needed, an eligible
candidate outside $D$ exists.

The selected candidate satisfies $G_{a_t}(t)<(1+\theta)B$.
Moreover, monotonicity gives $B\le M_t$ throughout the phase.
Therefore
\[
  \cost_t(C_t)=f_{a_t}(t)\le G_{a_t}(t)
  <(1+\theta)B\le(1+\theta)M_t.
\]
This argument also applies at phase boundaries because a new baseline
is set before the output is chosen.
\end{proof}

\subsection{Bounding switches and per-vertex recourse}
\label{subsec:online-recourse}

We first bound outer switches, separately from the changes inside the
candidate processes.
Let $S$ be the total number of outer switches, and let $s$ be the
number of positive phases. If $s>0$, write their successive baselines
as $B_1,\ldots,B_s$.
Define
\begin{equation}\label{eq:phase-count-parameter}
  H=1+\left\lceil
       \log_{1+\theta}\!\left(m\binom n2\right)
     \right\rceil.
\end{equation}
The expression is well defined because $n\ge2$, $m\ge3$, and $\theta>0$.
Every positive score is at least $1/m$, while every score is at most
$\binom n2$. Multiplicative increases between phase baselines therefore
permit only logarithmically many phases.

\begin{lemma}[Number of outer switches]\label{lem:outer-switches}
For every realization of the sampled family,
\[
  s\le H=O\!\left(\eps^{-1}\log(2mn)\right),
  \qquad
  S\le K(1+H).
\]
\end{lemma}
\begin{proof}
Each distance is an integer between $0$ and $\binom t2$.
Consequently every current cost, history score, and minimum history score
belongs to the grid
\[
  \left\{\frac jm:
     j\in\{0,1,\ldots,m\binom n2\}\right\}.
\]
Every positive baseline therefore lies in $[1/m,\binom n2]$.
The rule for starting a new phase gives
$B_{j+1}\ge(1+\theta)B_j$ for $1\le j<s$.
If there is a positive phase, it follows that
\[
  (1+\theta)^{s-1}\frac1m
  \le B_s\le\binom n2,
\]
and hence $s\le H$. The same conclusion is immediate if $s=0$.
Since $0<\theta=\eps/4<1$ and
$\log(1+\theta)\ge\theta/2$, the stated asymptotic bound on $H$ follows.

During the zero stage, a selected candidate is replaced only when
its history score becomes positive. It can never be selected again
during that stage. Thus there are at most $K-1$ switches within
the zero stage.
Within a positive phase, a selected candidate is replaced only after
becoming ineligible; it is then discarded and cannot return in that phase.
There are at most $K-1$ switches within each positive phase.
Allow one additional switch for entry into each positive phase.
Altogether,
\[
  S\le (K-1)+sK\le K(1+H).
\]
This upper bound also covers executions with an empty zero stage or
with no positive phase.
\end{proof}

An outer switch may change every previously assigned vertex's identifier,
so it is charged once to each such vertex.
All other identifier changes come from the internal trajectory of the
currently selected process. Because every process persists even while
unselected, returning to a candidate does not restart its internal
recourse budget.

\begin{lemma}[Per-vertex recourse]\label{lem:online-recourse}
For every realization of the sampled family and every vertex $v$,
\begin{align}
  \operatorname{rec}(v)
  &\le S+\sum_{a\in\A}\operatorname{rec}_a(v) \notag\\
  &\le K(1+H)+L_{\rm tri}q_{\rm A}\lceil\log_2 n\rceil
       \label{eq:recourse-decomposition}\\
  &=O_{\eta,q_{\rm A}}\!\left(
       \eps^{-2}
       \log\frac{2n}{\zeta}\,
       \log\frac{2mn}{\zeta}
     \right). \notag
\end{align}
\end{lemma}
\begin{proof}
Consider a time after $v$ has arrived at which its output identifier
changes. If the selected candidate changes, charge this change to that
outer switch. Otherwise the candidate index in
\eqref{eq:output-identifiers} stays fixed, so the local identifier
of $v$ in that candidate must have changed. Charge this change to the
corresponding internal-recourse event.
No internal event is charged more than once, proving the first inequality.

Input candidates have no internal recourse.
For triple candidates, apply \eqref{eq:internal-recourse}.
Combining with \cref{lem:outer-switches} gives
\eqref{eq:recourse-decomposition}.
Finally, substitute \eqref{eq:candidate-count} and the bound on $H$.
Since $\eps<1$,
$\log n\le\log(2mn/\zeta)$, and
$\log(2mn)\le\log(2mn/\zeta)$, the internal-recourse term is absorbed
by the displayed asymptotic bound.
\end{proof}

\subsection{Proof of the main theorem}\label{subsec:online-main-proof}

We can now combine the probabilistic existence of good candidate
histories with the deterministic selection and recourse guarantees.
The remaining multiplicative loss in selection is absorbed by the
accuracy parameter $\eps$.

\begin{proof}[Proof of \cref{thm:online-main}]
The cases $n=1$ and $m\le2$ were handled immediately after the theorem.
For $n\ge2$ and $m\ge3$, sample and maintain the candidate family from
\cref{subsec:online-candidates} and use
\cref{alg:online-selection} for the output.

By \cref{lem:simultaneous-history-event}, the event $\mathcal E$ holds
with probability at least $1-\zeta$.
On this event, \cref{lem:online-phase-cost} gives, simultaneously for
all $t\in[n]$,
\[
  \cost_t(C_t)
  \le(1+\theta)M_t
  \le(1+\theta)R\OPT_t.
\]
Using $\theta=\eps/4$, $R=2-\alpha_*+\eps/2$, and $R<2$, we have
\[
  (1+\theta)R
  =R+\frac{\eps}{4}R
  <2-\alpha_*+\frac{\eps}{2}+\frac{\eps}{2}
  =2-\frac{2}{3\eta+5}+\eps.
\]
This proves \eqref{eq:online-ratio}, including prefixes with
$\OPT_t=0$.
For every realization of the samples, independently of $\mathcal E$,
\cref{lem:online-recourse} proves \eqref{eq:online-recourse-main}.
\end{proof}

\paragraph{Scope of the result.}
The algorithm uses a known horizon and an oblivious input sequence.
Its randomness is confined to the initial candidate sampling.
Exact scoring uses all input partitions, and all auxiliary processes
are updated at every arrival. The theorem does not claim a fast-update
implementation. The role of $\Agree$ is precisely its simultaneous,
deterministic approximation guarantee together with persistent
per-vertex recourse; these properties are used separately in the
history bound and in the final recourse accounting.
